# ⚠️ This repository is no longer actively maintained

Development of the Jumper frontend has moved to a **private repository**. This public repo remains available as a **reference**, but it is now **frozen** — it will not receive further updates, fixes, or support, and issues and pull requests are no longer monitored.

## Why the move?

As the Jumper website has grown, its codebase and footprint have become increasingly complex to maintain in the open. Keeping development public added meaningful overhead to our release process. Moving to a private repository lets us ship changes faster and iterate more efficiently.

The code here reflects Jumper's state at the time of this change and is provided **as-is**, for reference purposes only.

Jumper remains live and fully supported at **[jumper.xyz](https://jumper.xyz)**.
